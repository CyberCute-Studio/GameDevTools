CyberCute Dev Tools - Release Notes
===================================

Version 1.0.0 - release candidate
---------------------------------

This is the first version. It is a release candidate: the final validation is
still open, and the checks listed under "Not yet verified" have not been run.
Checks that drive the application with real mouse and keyboard input were run
by script on this build, as the x64 executable under emulation on Windows 11 on
Arm, rather than by a person on x64 hardware.

What it does

Screenshot
- Free Rectangle, exact-size Preset Rectangle, and Full Display capture.
- A preset frame stays on top while clicks inside it reach the application
  underneath. Move it by its border or by exact pixels with the arrow keys.
- Every capture goes to the clipboard and to a PNG or JPEG file, each reported
  separately.
- A configurable global shortcut, Ctrl+Alt+S by default. While you work in
  another application, a small card reports each result without taking the
  focus, and a problem stays until you dismiss it.

Image Resizer
- Resize PNG and JPEG images in bulk, added by picker or drag and drop.
- Stretch, Fit, and Crop to Fill, with reusable presets.
- Keep Source Format, PNG, or JPEG output, with transparency kept in PNG and
  flattened against a color you choose in JPEG.
- Rename, Skip, or confirmed Overwrite when a file already exists. Source images
  are never modified or overwritten.
- Progress, cancellation, and a result for every file. One bad file never stops
  the others.

Across the application
- Separate built-in and custom presets for each tool.
- Settings kept per user, with backups before any recovery or reset.
- Works offline, with no account, telemetry, or update check.
- A dark theme, with full keyboard access in the main window and support for
  the Windows contrast themes.

Requirements

64-bit Intel or AMD PC with Windows 11. No administrator rights are needed.
Windows 10, Windows on Arm, and 32-bit Windows are not supported.

Upgrading from GameDevTools

Builds named GameDevTools were development builds. The first launch copies their
settings and leaves the old folder in place. README.txt has the details.

Not yet verified

These have not been run, so this version makes no claim about them:

- x64 Windows 11 on real hardware, including the reference machine. Testing so
  far ran on Windows 11 on Arm, natively and as the x64 build under emulation.
- Any Windows 11 release other than build 26300, where the combined run took
  place, and build 26200, where the Screenshot module's own run took place.
- Display scaling above 100%, mixed scaling, displays with negative coordinates,
  rotated displays, and unplugging a display during a selection. None of these
  has run on real displays. Automated checks cover the calculations for all but
  rotated displays, which have none.
- A clean machine, a real screen reader, the contrast themes switched on, a real
  sign-out during a job, and a run with network adapters off.
- A person confirming that the keyboard focus is visible on every control. The
  automated checks follow where the focus goes, not how it looks.
- Saving to FAT32 or exFAT drives, network shares, OneDrive folders, or a drive
  that fills up.
- Real clipboard sync with a signed-in account.
- Pasting a capture into an Office application, as Office on the test machine
  was not signed in. Pasting into Paint was checked.

Known issues

Sections 10 and 11 of USER-GUIDE.txt describe each of these and any step to
take.

- If a save fails and its temporary file cannot be removed, a
  .gamedevtools-*.tmp file may hold the capture's only copy. Do not delete one
  before reading section 11.
- Under x64 emulation, the Free Rectangle overlay took slightly longer than its
  300 ms target in 2 of 6 test batches, at 312 and 317 ms. Whether this happens
  on x64 hardware is not yet known.
- On mixed scaling, the second line of the capture toolbar's message can be cut
  off.
- DRM-protected content can capture as black with no error, as Windows reports
  none.
- After a capture, the keyboard focus stays outside the application. Use Alt+Tab
  to return to it.
- The first time File Explorer shows a folder, Open Folder can leave the saved
  file focused rather than highlighted. Explorer's own select command does the
  same.

Deferred from the requirements

- Following the Windows light app mode (UX-008). The application has one dark
  theme, which it keeps when apps are set to light; under a Windows contrast
  theme it uses that theme's colors. A light theme is a possible future
  addition.

Distribution

- Portable ZIP with a SHA-256 checksum. There is no installer.
- Not code-signed, so Windows SmartScreen may warn on first run.
- No automatic updates. To update, replace this folder's files with those from
  the new ZIP, extracting it where README.txt says so that it does not create a
  second folder inside this one.
- Released under the MIT License, in LICENSE.txt. THIRD-PARTY-NOTICES.txt covers
  the components it includes.

See USER-GUIDE.txt for how to use the application and for its full list of
limitations.
